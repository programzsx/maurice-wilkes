# Maurice Wilkes 设计说明

## 目标

建立一个自己的名词词典。人名、物品名、概念名都归入名词，用同一张表先收集起来。系统暂时不做复杂关联，先把“命名、描述、排序、检索”这条路径做顺。

## 数据表

表名：`dict_noun`

基础字段：

- `id`：字符串雪花 ID
- `create_time`：创建时间，秒级时间戳字符串
- `update_time`：更新时间，秒级时间戳字符串

统计字段：

- `sort_order`：排序值，数值越大越靠前
- `random_int`：自增随机值，保留给随机抽取和稳定辅助排序

业务字段：

- `name`：名词名称，唯一
- `description`：描述

## API

- `GET /api/dict-nouns?q=&page=1&page_size=20`：分页列表
- `GET /api/dict-nouns/random?limit=1`：随机抽取
- `GET /api/dict-nouns/{id}`：详情
- `POST /api/dict-nouns`：新增
- `PUT /api/dict-nouns/{id}`：修改
- `DELETE /api/dict-nouns/{id}`：删除

## 页面

React 单页应用。左侧是录入表单，右侧是检索、列表和详情。第一屏即工作台，不设置营销落地页。
