# Maurice Wilkes 设计说明

## 目标

建立一个自己的词典。不是只收集名词，而是按十二词性收集语言材料：名词、动词、形容词、数词、量词、代词、副词、介词、连词、助词、叹词、拟声词。系统暂时不做复杂关联，先把“命名、描述、排序、检索、随机抽取”这条路径做顺。

更深一层的动机是提炼模式：十二词性虽然业务含义不同，但管理结构相同。每一类词都应有同样的基础字段、统计字段、业务字段和 CRUD API。代码里用共享模型 mixin、统一 schema、统一路由逻辑承载这个模式。

## 数据表

表名：

- `dict_noun`：名词
- `dict_verb`：动词
- `dict_adjective`：形容词
- `dict_numeral`：数词
- `dict_classifier`：量词
- `dict_pronoun`：代词
- `dict_adverb`：副词
- `dict_preposition`：介词
- `dict_conjunction`：连词
- `dict_particle`：助词
- `dict_interjection`：叹词
- `dict_onomatopoeia`：拟声词

基础字段：

- `id`：字符串雪花 ID
- `create_time`：创建时间，秒级时间戳字符串
- `update_time`：更新时间，秒级时间戳字符串

统计字段：

- `sort_order`：排序值，数值越大越靠前
- `random_int`：自增随机值，保留给随机抽取和稳定辅助排序

业务字段：

- `name`：词条名称，唯一
- `description`：描述

## API 模式

- `GET /api/dict/types`：十二词性元数据
- `GET /api/dict/{word_type}?q=&page=1&page_size=20`：分页列表
- `GET /api/dict/{word_type}/random?limit=1`：随机抽取
- `GET /api/dict/{word_type}/{id}`：详情
- `POST /api/dict/{word_type}`：新增
- `PUT /api/dict/{word_type}/{id}`：修改
- `DELETE /api/dict/{word_type}/{id}`：删除

其中 `word_type` 取值：`noun`、`verb`、`adjective`、`numeral`、`classifier`、`pronoun`、`adverb`、`preposition`、`conjunction`、`particle`、`interjection`、`onomatopoeia`。

兼容旧名词接口：

- `/api/dict-nouns`

## 页面

React 单页应用。左侧是十二词性切换和录入表单，右侧是检索、列表和详情。第一屏即工作台，不设置营销落地页。
