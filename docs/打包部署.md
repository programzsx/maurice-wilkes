# Maurice Wilkes 打包部署指南

## 端口

- 前端：`5180`
- 后端：`8010`

## 本地构建

后端：

```bash
cd server
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8010
```

前端：

```bash
cd web
npm install
npm run build
npm run preview
```

## 阿里云部署

在项目根目录执行：

```bash
bash aibase/sre-deploy/deploy.sh
```

Windows 环境如果 WSL 的 `bash` 不可用，可以执行：

```powershell
powershell -ExecutionPolicy Bypass -File aibase/sre-deploy/auto-deploy.ps1
```

脚本会完成：

- 构建 React 前端
- 打包 `server/` 与 `web/dist/`
- 上传到 ECS `8.160.174.178`
- 创建或复用 `/home/maurice-wilkes/server/.env`
- 创建 systemd 服务 `maurice-wilkes.service`
- 配置 Nginx 监听 `5180`
- 验证 API 与 Web 访问

公网访问还需要在阿里云安全组中放行入方向 TCP `5180` 和 `8010`。如果安全组未放行，ECS 本机健康检查会通过，但外部浏览器会连接超时。

部署后：

```bash
ssh root@8.160.174.178 "systemctl status maurice-wilkes"
ssh root@8.160.174.178 "journalctl -u maurice-wilkes -f"
```
